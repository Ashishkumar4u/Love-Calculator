💖 Love Calculator

This is a simple Love Calculator project I made using **HTML, CSS and JavaScript**.

The idea is pretty simple — enter two names and the calculator gives a love compatibility percentage. It's mainly a fun project and was also a good way for me to practice basic web development and JavaScript.

🌐 Live Demo

You can try it here:

https://ashishkumar4u.github.io/Love-Calculator/

🛠️ Technologies Used

- HTML
- CSS
- JavaScript

## 🚀 Run It Locally

If you want to run the project on your computer:

```bash
git clone https://github.com/Ashishkumar4u/Love-Calculator.git
```

Then open the project folder and run `index.html` in your browser.

You can also use **Live Server** in VS Code.



## 💡 About the Result

The percentage shown by the calculator is just for fun. It isn't meant to actually measure love or relationship compatibility.
